# 리스히나 (Risu Hina) BETA

**RisuAI 봇 제작·수정 통합 플러그인.** 봇 카드, 로어북, 정규식, Lua, 에셋, 그리고 챗까지 한 화면에서 만들고 고친다.
직접 편집해도 되고, AI 에이전트 **히나**에게 말로 시켜도 된다. 히나가 고친 내용은 전부 **제안**으로 올라오고, 승인한 것만 반영된다.

**[최신 릴리스 다운로드](../../releases/latest)**

---

## 무엇을 하나

### 01 봇 제작 — 기획부터 완성까지

- **시뮬봇·일인봇 설계.** 인기 봇 14종을 분석해 만든 제작 방법론 스킬이 들어 있다. 세계관·인물·NPC·사건을 로어북으로 나누는 법, 캐릭터 시트와 매력 관리, 관계 진행, 이벤트와 서사 페이싱을 히나가 알고 쓴다.
- **로어북 설계와 작성.** 총합 로스터와 개별 상세 항목, 우선순위 대역, 데코레이터(`@@depth`, `@@position` …), 폴더 구성을 봇 전체 순서까지 보고 제안한다.
- **상태창 · 옵션 패널 · 에셋 출력식.** 상태 태그 지시문, 정규식으로 HTML 렌더, 배경 CSS, 설정 버튼으로 여는 슬라이딩 패널, 감정·의상별 이미지 태그와 폴백까지 한 번에 만든다.
- **정규식과 Lua.** editinput/editoutput/editprocess/editdisplay 선택과 순서, 리롤에 안전한 상태 저장, 보조 모델(axLLM) 호출 같은 고급 메커니즘을 최신 RisuAI 소스로 검증한 기준으로 짠다. 필요하면 히나가 최신 RisuAI·PocketRisu 소스를 직접 받아 봇과 대조한다.
- **새 봇으로 저장.** 지금까지 고친 상태를 원본은 그대로 둔 채 새 봇으로 복제한다.

### 02 봇 수정 — 카드의 모든 칸

- 메타(설명·인사말·시스템 프롬프트·예시 대화·크리에이터 노트·기본 변수·lowLevelAccess), 봇 로어북, 정규식(플래그 포함), Lua 트리거, 에셋을 편집한다.
- 긴 Lua 는 필요한 부분만 찾아 부분 교체하고, 파일로 꺼내 고쳐 넣을 수도 있다.
- 변경은 **스냅샷**으로 남고 언제든 되돌린다. RisuAI 쪽에서 바뀐 내용과는 3-way 병합으로 충돌을 가린다.
- 다 고치면 **반영** 한 번으로 RisuAI 카드에 써 넣는다.

### 03 에셋 스튜디오 — 이미지 생성과 검수

- NovelAI 이미지 생성: 스타일 카드, 캐릭터 레퍼런스, 씬 × 캐릭터 × 장수 배치, 인페인트.
- **검수 탭**: 후보를 넘겨 보며 채택·버림을 고르고, 히나에게 직접 보고 검수시킬 수도 있다(비전 모델).
- 채택한 이미지를 봇 에셋으로 등록한다. 이름 규칙·감정 누락 점검·중복 찾기를 도와준다.

### 04 챗 수정 — 이미 진행한 이야기 고치기

- 챗 턴을 펼쳐 놓고 직접 고치거나, 히나에게 "상태창 숫자가 어긋난 곳 맞춰 줘", "이 사건을 이렇게 바꿔 줘"라고 시킨다. 앞뒤 흐름에 맞게 일관되게 고친다.
- 챗 로어북, 장기기억, 챗 변수도 같은 방식으로 다룬다.
- 긴 챗의 앞부분을 요약해 로어북으로 옮기는 "요약 이사", 새 챗 사본으로 저장하기.

### 05 에이전트 히나

- 멀티턴 에이전트. 계획을 세우고 할 일을 추적하며, 스킬(작업 절차)을 필요할 때 불러 쓴다. 스킬은 직접 추가·수정할 수 있다.
- 파이썬 샌드박스(현재 봇 데이터만 접근), 파일 공간(`projects/` 참고 자료 · `studio/` 이미지 · `hina/` 작업 폴더), 웹 검색, 이미지 보기.
- 모델: OpenAI 호환이면 무엇이든 된다. OpenAI, Anthropic, Google Gemini, Vertex AI, Ollama Cloud, OpenRouter, DeepSeek, xAI, Mistral, Groq 등 프로필이 들어 있고, ChatGPT(Codex) 로그인도 된다.

> 멀티턴 에이전트는 호출이 많습니다. 비용 부담이 적은 모델을 권합니다.

## 구성

| 부분 | 어디에 | 하는 일 |
|---|---|---|
| **백엔드** | PC 나 서버에 상주하는 파이썬 서버(인터프리터 동봉) | 챗·봇·에셋 저장, 에이전트 실행, 파일 공간, 이미지 생성 |
| **플러그인** `Risu.Hina.Plugin.js` | RisuAI(웹 또는 PocketRisu) 안 | 화면. 백엔드에 HTTP 로 붙는다 |

플러그인과 백엔드는 버전 앞 두 자리(major.minor)가 같아야 통신한다. 백엔드는 설정 화면에서 업데이트하고, 플러그인은 RisuAI 플러그인 화면의 `+` 로 업데이트한다.

## 설치

[릴리스](../../releases/latest)에서 `Risu.Hina.<버전>.<OS>.x64.Auto.Install.Package.zip` 을 받아 원하는 폴더에 푼다. 파이썬을 따로 깔 필요는 없다.

```
setup.bat          # Windows
./setup.sh         # Linux
```

`Risu.Hina.Plugin.js` 를 RisuAI 플러그인 화면에 추가하고, 챗 화면의 **Risu Hina** 버튼 → ⚙ → **연결**에 백엔드 주소를, **에이전트**에 모델 자격증명을 넣는다.

### 방법 1 — PocketRisu 와 같은 PC

가장 간단하다. 같은 PC 에서 PocketRisu 와 리스히나를 함께 돌린다. 에셋은 PocketRisu DB 를 직접 읽어 빠르게 동기화된다.

```
PocketRisu (브라우저)  ←→  리스히나 백엔드 (같은 PC)
```

연결 주소: `http://127.0.0.1:6020` (토큰 불필요)

### 방법 2 — 웹 RisuAI / 다른 기기 + Tailscale

폰이나 다른 기기의 RisuAI 에서 내 PC 의 백엔드에 붙는다.

```
웹 RisuAI / PocketRisu (폰·다른 기기)
  └─ Tailscale 네트워크 ─→  리스히나 백엔드 (내 PC)
```

연결 주소: `http://<Tailscale IP>:6020`. 루프백이 아니면 토큰이 필수다. 최초 기동 때 콘솔에 나오는 토큰(`data/token.txt`)을 연결 설정에 넣는다. 웹 RisuAI(https)에서 붙으려면 HTTPS 주소(Tailscale serve, Cloudflare 터널 등)와 RisuAI 의 **Use Plain Fetch** 설정이 필요하다.

### 재부팅 후 자동 기동

```powershell
setup.bat -Service       # Windows (NSSM, 관리자 권한)
uninstall.bat            # 서비스 제거
```

```bash
./setup.sh --service     # Linux (pm2)
./uninstall.sh
```
