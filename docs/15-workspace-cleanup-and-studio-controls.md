# 워크스페이스 정리와 스튜디오 생성 컨트롤

워크스페이스 중앙 패널은 목록·미리보기 모두 상위 폴더 이동, 새 폴더 생성,
파일 업로드 버튼을 제공한다. 상위 폴더가 없는 최상위 영역에서는 이동을,
읽기 전용·가상 문서 영역에서는 생성과 업로드를 비활성화한다.

워크스페이스 트리 하단은 세 버튼이다: **전체 보기/이 봇만**, **숨김 파일 표시**,
**임시파일 정리**. (봇별 "이 봇 정리" 버튼과 "AI temp/숨김 정리" 는 2026-09-20 에
하나로 합쳤다. `POST /files/clean` 자체는 남아 있다.)

**임시파일 정리**는 `space/hina` 안의 scratch, 알려진 캐시 디렉터리,
`_agent_run.py`, 임시 확장자 파일, 그리고 예전 버전이 `hina/.cleanup/` 에
보관해 둔 것을 찾아 개수·용량을 보여 주고, 확인하면 **되돌릴 수 없이 삭제**한다
(사용자 지시: "백업하지 말고 그냥 삭제"). 비워진 하위 폴더는 함께 지우되
`scratch/`·`scripts/` 루트는 남긴다. 응답은 `removed`·`freed`·`failed` 다.

프로젝트·스튜디오 영역, 스킬, Git 디렉터리와 worktree의 `.git` 파일,
숨김 설정 파일은 대상에서 제외한다. 심볼릭 링크와 Windows junction은 따라가지
않는다. AI 턴이 진행 중이면 정리를 거절하며, 미리보기 이후 대상 목록이나 파일의
크기·수정 시간이 바뀌면 목록을 다시 확인하도록 한다. 이동 실패는 건수로 표시한다.

에셋 스튜디오의 장수·생성 시작·취소 컨트롤은 좌측 패널의 스크롤 영역 밖에
한 번만 생성한다. 프롬프트·캐릭터·OUTPUT 전환 후에도 같은 컨트롤이 유지되며,
현재 작업 상태에 따라 생성/취소 표시가 갱신된다.

AI 메모리·자동 컨텍스트 압축 카드는 설정 → 에이전트 → 고급 설정 안에 있다.
메모리 설정 저장 후 비용 예상 표시도 새 컨텍스트 값으로 갱신된다.

쉘 제한은 사용자가 이번 변경에서 제외했으므로 기존 동작을 유지한다.
