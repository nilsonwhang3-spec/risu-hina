# 에이전트 메모리와 작업 맥락 (0.15.1)

설정 → 에이전트에서 메모리와 자동 맥락 압축을 설정한다. 둘 다 기본으로 켜져 있다.

## 메모리

에이전트는 확인한 사용자 선호, 결정, 진행 중인 작업의 핵심 정보를 `remember_note`로 기록하고 `recall_notes`로 검색한다. 기본 저장 범위는 현재 프로젝트다. 모든 프로젝트에 적용하는 사실만 공통 메모리에 저장한다. 설정 화면에서 내용을 직접 추가·수정·삭제할 수 있다.

메모리는 `data/agent-notes`에 저장되어 새 대화와 서버 재시작 후에도 유지된다. 동시 수정은 리비전으로 검사하고 최근 수정 이력 10개를 보관한다. 메모리는 현재 사용자 지시보다 우선하지 않는다. 자격 증명과 전체 대화 원문을 메모하도록 지시하지 않는다. 절차를 재사용하는 스킬과는 별도 기능이다.

## 자동 압축

각 모델 요청 직전에 입력량을 추정한다. 긴 대화뿐 아니라 한 턴에서 툴 호출을 반복할 때도 검사한다. 설정한 컨텍스트 크기에서 출력과 툴 정의에 필요한 공간을 제외하고 여유를 둔다. 기본 컨텍스트 크기는 128,000 토큰이며 모델에 맞게 변경할 수 있다. 토큰 수는 추정치다.

오래된 완료된 툴 교환을 요약하고 최신 사용자 지시와 최근 툴 호출/결과 쌍을 보존한다. 큰 툴 결과는 앞뒤를 남겨 줄인다. 요약 실패 시 완료 여부를 단정하지 않는 기록 발췌를 사용한다. 에이전트가 `compact_context`로 직접 압축을 요청할 수도 있다. 압축 발생은 대화 화면에 표시되고 최근 기록은 설정에서 확인한다. 요약 요청의 사용량도 비용 기록에 포함된다.

## JOB 및 파일 화면

배치 목록은 최근 완료 작업과 모든 실행·대기 JOB을 함께 조회한다. AI는 `studio_job`으로 조회하고 `studio_cancel`로 취소한다. 실행 중 취소는 현재 이미지 처리가 끝난 뒤 적용하며 이미 저장한 이미지는 유지한다.

이미지 상세는 원본을 사용하는 공통 모달로 열리고 원본 크기 확대를 지원한다. OUTPUT과 워크스페이스는 파일 클립보드를 공유한다. Ctrl+C 또는 Ctrl+X 후 대상 폴더에서 Ctrl+V로 복사·이동한다. 일부 이동이 실패하면 해당 항목은 클립보드에 남는다.
